═══ 2. ЖЁСТКИЕ ПРАВИЛА ═══

2.1. Не пиши код без подтверждения. Сначала обсуждение архитектуры. Код — только после «код», «применяй», «пиши», «делай».

2.2. Формат выдачи кода. Каждое изменение — двумя раздельными блоками. ОБЯЗАТЕЛЬНО указывай имя файла рядом с каждым ПОИСК:

**Файл: engine.js**
**ПОИСК:**
[точный фрагмент из исходного файла]

**ЗАМЕНА:**
[готовый фрагмент для вставки]

Запрещено: git-маркеры (<<<<<<<, =======, >>>>>>>), объединять поиск и замену в один блок, выдавать файл целиком (кроме текстовых документов: SYSTEM INSTRUCTIONS, README, юридические тексты), прятать код в спойлеры, писать «остальной код без изменений». Комментарии к каждому изменяемому блоку обязательны.

Если патч затрагивает несколько файлов — каждый блок ПОИСК/ЗАМЕНА предваряется явной строкой **Файл: <имя>**. Порядок применения блоков внутри одного сообщения — сверху вниз. Патч не должен каскадно ссылаться на код, изменённый в этом же сообщении (иначе у пользователя не найдётся ПОИСК). Зависимые правки — в разных сообщениях.

2.3. Не ломай работающее. Стабильные механики (TCG-бой, FTUE 12 шагов, формула Возвышения, синергии, экономика экспедиций, стихийный круг, Мастерство M1–M100, античит-флаги, IS_DEV_MODE, P9-валидация) — не трогать без явного запроса.

2.4. Типографика. Минимум 11px. Заголовки 12–24px. Cinzel, serif — заголовки, кнопки, ранги, имена. Inter, sans-serif — статы, числа, описания.

2.5. Эмодзи. В коде — никогда. Только SVG или <img> с ассетами. В чат-ответах допустимо для структуры, без злоупотреблений.

   • IS_DEV_MODE — единый флаг dev-режима. Активация: hostname ∈ {localhost, 127.0.0.1, 0.0.0.0} ИЛИ ?debug=1 в URL. Override: ?debug=0 отключает принудительно даже на localhost.
   • devLog(...args) — обёртка над console.log, пишет только при IS_DEV_MODE.
   • Dev-команды (доступны только под IS_DEV_MODE): skipFtue(), resetFtue(), testAscensionRitual(), testArenaPromote(), testArenaDemote(). В проде — undefined.
   • URL-параметр ?skipftue=1 работает только под IS_DEV_MODE.
   • При сбросе прогресса через hard reset FTUE запускается заново.
   • Обязательный сброс SW после каждого патча: Application → Service Workers → Unregister + Application → Storage → Local Storage → Delete (по домену). ⚠️ НЕ использовать «Clear site data» — сносит куки VK.
   • Бамп CACHE_NAME в sw.js + ?v= в index.html + BUILD_VERSION в engine.js при каждом релизе (три числа = одна версия).
   • Правило 0 оптимизации: перед любым анализом производительности проверить chrome://gpu — Hardware accelerated: Compositing и Rasterization должны быть включены.
